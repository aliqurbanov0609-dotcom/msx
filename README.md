MSX PERSONAL LAUNCHER 1.0

STRUCTURE
msx/start.json
msx/menu.json

IMPORTANT
The Media Station X Start Parameter field accepts only the server/hostname.
For this launcher enter ONLY:
msx-c3ug.vercel.app

Do NOT enter https:// and do NOT enter any slash in the MSX field.

DEPLOYMENT
1. Upload the complete project to the Vercel project used by msx-c3ug.vercel.app.
2. Keep the folder named msx exactly as shown above.
3. Redeploy.
4. Test in Safari:
   https://msx-c3ug.vercel.app/msx/start.json
   https://msx-c3ug.vercel.app/msx/menu.json
5. In Media Station X:
   Settings -> Start Parameter -> Setup
   Enter only: msx-c3ug.vercel.app
6. If MSX asks for Security Lock for HTTPS, enable it.

The slash characters shown in the browser URLs are normal. They are NOT entered into the MSX Start Parameter field.
